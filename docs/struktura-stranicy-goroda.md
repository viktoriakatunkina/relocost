# Структура страницы города (на примере Тбилиси, /city/tbilisi)

Порядок блоков сверху вниз, как они реально идут в коде (`app/[locale]/city/[slug]/page.tsx`). Пакеты и цены: **Места — 19₽**, **Расходы — 49₽**, **Комбо (расходы+места) — 59₽**.

1. **Хлебные крошки** — навигационная цепочка (Главная / Страна / Город)
2. **Шапка города (Hero)** — фото, название, страна, бейдж источника данных
3. **Быстрые факты** — валюта, климат, население, виза для россиян и т.п. (иконки-плашки)
4. **Счётчик «В избранном»** — сколько раз город добавили в избранное
5. **Якорная навигация** — панель-меню (Калькулятор / Цены / Виза / За и против / Отзывы / FAQ), прилипает при скролле
6. **Индекс качества жизни (карточка)** — краткий балл 0-100 с грейдом A-F
7. **Вердикт «Стоит ли переезжать»** — плюсы/минусы/для кого подходит, коротким резюме
8. **Быстрые цены-якоря** — строка с парой ключевых цифр цен
9. **Краткое резюме о городе** (Summary)
10. **Подробное описание города** (About) — развёрнутый текст
11. **Фотогалерея**
12. **«Сколько нужно на месяц»** (MonthlyBudget) — переключатель 1 человек/Пара/Семья с ребёнком
    - **Бесплатно:** ничего из цифр. Итоговая сумма и ВСЕ строки категорий (аренда/еда/транспорт/ЖКХ) заблюрены
    - **Платно:** весь блок открывается пакетом «Расходы» (49₽)
13. **Калькулятор переезда** (Calculator) — переключатель Эконом/Стандарт/Комфорт
    - **Бесплатно:** ничего из цифр — построчная разбивка и итоговая сумма заблюрены
    - **Платно:** пакет «Расходы» (49₽)
14. **Таблица цен по категориям** (PricesTable) — вкладки Аренда/Еда/Транспорт/ЖКХ и т.д.
    - **Бесплатно: первые 3 позиции** в каждой категории
    - **Платно:** остальные — пакетом «Расходы» (49₽). У аренды на 18 пилотных городах (см. ниже) позиций стало заметно больше — обычно ~22 вместо ~7, то есть под замком там теперь ~19 позиций вместо ~4
15. **Тизер «Маршруты на день»** — только на 18 городах, где есть эта фича (список ниже), на остальных 157 городах блока нет вообще
16. **Качество жизни (детальный блок)** — расширенная версия блока из п.6, с разбивкой по параметрам
17. **Сравнение с Москвой** (CostVsMoscow) — бар-чарт по категориям, **полностью бесплатно**
18. **«Что это значит для Вас»** (SecondPersonSummary) — короткий текст-вывод
19. **«Сколько нужно на жизнь»** (EarnEquivalent) — слайдер «ваш бюджет в Москве»
    - **Бесплатно:** сам слайдер и общая механика — да, интерактивен
    - **Платно:** точный результат (сумма-эквивалент) заблюрен, пакет «Расходы» (49₽)
20. **Сложность переезда по категориям** (DifficultyBars) — виза/язык/бюрократия и т.п., **бесплатно**
21. **Индекс качества жизни** (LivingScore, ещё один вариант блока) — **бесплатно**
22. **Работа и трудоустройство** (CityWork) — **бесплатно**
23. **«Лучшие места»** (BestPlaces) — кафе/рестораны/районы/рынки/коворкинги/достопримечательности
    - **Обычные 157 городов:** 2 места бесплатно / 2 места платно (без фото)
    - **18 пилотных городов** (Тбилиси, Ереван, Дубай, Бали, Пхукет, Батуми, Паттайя, Самуи, Анталья, Аланья, Стамбул, Лимассол, Будва, Тенерифе, Чиангмай, Нячанг, Дананг, Шарм-эль-Шейх): **2 места бесплатно / 10 мест платно**, у всех 12 есть фото (у платных — тоже блюрятся)
    - **Платно:** пакет «Места» (19₽)
24. **«Районы для жизни»** (CityDistricts) — **полностью бесплатно**. На мобильном — карусель в 2 строки со свайпом вбок (поправлено сегодня)
25. **Шаги оформления визы** (VisaSteps) — **полностью бесплатно**, паywall на этом блоке нет
26. **Партнёрские предложения** (CityPartners) — авиабилеты/жильё/страховка, рекламные блоки (Travelpayouts + Черепаха), только для зарубежных городов
27. **Отзывы переехавших** (Reviews, из реальных текстовых отзывов) — **полностью бесплатно**. На мобильном — горизонтальная карусель со свайпом (поправлено сегодня)
28. **Отзывы (второй блок)** (CityReviews) — отдельный хардкод-набор отзывов с датами, **полностью бесплатно**
29. **Народные цены** (CrowdPriceFeed + форма) — цены, присланные пользователями + форма добавить свою
30. **FAQ** (CityDynamicFAQ, автогенерируемый) — сейчас **2 вопроса**: «Что входит в стоимость жизни» и «Как переехать» — **полностью бесплатно**. Раньше было 5 вопросов, но 3 из них называли точный бюджет/аренду в открытую — убрали сегодня, чтобы не обесценивать платные пакеты
31. **Статьи блога об этом городе** (CityArticles) — ссылки на релевантные статьи
32. **Перекрёстные ссылки** (CrossLinks)
33. **Похожие города** (SimilarCities)
34. **Предложения сравнить** (CompareSuggestions) — ссылки на /compare с другими городами
35. **Бейдж для блогеров** (BadgeEmbed) — виджет-приглашение встроить бейдж города к себе на сайт
36. **Футер**

## Отдельно, не в потоке страницы (плавающие элементы)

- **Закреплённая нижняя панель** (StickyBar) — постоянно видна внизу экрана, кнопки «Все цены — 49₽» и «Всё — 59₽» (или другой primary-пакет, если «Расходы» уже куплены)
- **Обработчик возврата с оплаты** (VerifyOnReturn) — невидимый, открывает доступ после успешной оплаты через ЮKassa

## Итого по деньгам на одной странице

Три платных входа с одной и той же ценой пакета «Расходы» (49₽) — MonthlyBudget, Calculator, PricesTable, EarnEquivalent — все открываются ОДНИМ и тем же платежом (это один пакет, не 4 разных покупки). Отдельно — «Места» (19₽) за BestPlaces. «Комбо» (59₽) открывает оба сразу.
